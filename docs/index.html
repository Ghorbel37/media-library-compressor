How bpp and quality are worked out

Bits per pixel is the file size relative to the resolution, the same formula mlc uses:

bpp = size in bytes x 8 / (width x height)

A photo is recompressed when it is larger than --min-size and its bpp is above --bpp (or above --target-bpp when that is set). Photos at or below the threshold are left alone.

The JPEG quality column is read from the file itself. A JPEG stores the tables its encoder used to round away detail, and most encoders (Pillow, which mlc uses, and libjpeg) build them by scaling the standard tables of the JPEG spec by the quality. The page finds the quality whose tables match.

A plain number means an exact match, as for files saved by mlc. "about" means the encoder used its own tables, as many phone cameras do, and the number is the closest standard quality. "custom tables" means they differ a lot from the standard ones, so treat that number as rough.
