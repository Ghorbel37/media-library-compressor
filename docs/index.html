How bpp is calculated

Bits per pixel is the file size relative to the resolution, the same formula mlo uses:

bpp = size in bytes x 8 / (width x height)

A photo is recompressed when it is larger than --min-size and its bpp is above --bpp (or above --target-bpp when that is set). Photos at or below the threshold are left alone.

The quality column is an estimate for typical phone photos re-encoded by mlo (Pillow). Detailed or noisy scenes land higher, plain scenes lower, and a camera's quality numbers use different tables, so treat it as a rough guide:
